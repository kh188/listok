# Листва — сайт о развитии лайфстайл-блога

Одностраничный адаптивный сайт на React и Vite.

## Запуск на компьютере

1. Открой папку `listva-blog` в VS Code.
2. Открой терминал VS Code (**Terminal → New Terminal**).
3. Один раз выполни `npm install`.
4. Запусти `npm run dev`.
5. Перейди по адресу, который появится в терминале (обычно `http://localhost:5173/`).

Чтобы остановить сайт, нажми `Ctrl+C` в терминале.

## Production-сборка

- `npm run build` создаёт готовую к публикации сборку в `dist/`.
- `npm run preview` показывает production-сборку локально.
- Для проверки в Lighthouse сначала выполни `npm run build`, затем `npm run preview` и проверь `http://localhost:4173/`. Проверка `http://localhost:5173/` оценивает dev-режим Vite и обычно показывает более низкую производительность.

Перед запуском на домене замени домен в метаданных, добавь реальные контакты и подключи обработчик формы к email или CRM. Сейчас форма интерактивна как демонстрация и не отправляет заявки на сервер.
